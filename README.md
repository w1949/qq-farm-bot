# qq-farm-bot Windows 单文件版

Windows x64 单文件 exe，内置抓包填 Code、账号定时启停和自动更新，双击即用，不需要装 Node 或配置环境。
本仓库只放发布产物：代码基线更新后重新打包、移植自有功能并发布，同时刷新固定更新清单。

## 下载

- 最新版：打开 [Releases 最新](https://github.com/w1949/qq-farm-bot/releases/latest)，下载里面的 `.exe` 即可
- 固定更新清单（客户端内置，无需填写、不可修改）：
  `https://github.com/w1949/qq-farm-bot/releases/download/manifest/latest.json`

> exe 是控制台子系统，双击会带一个终端窗口，关掉窗口程序就退出，属正常现象。

## 安装与使用

1. 双击 exe 启动，等 20–30 秒加载配置表，浏览器打开面板 `http://127.0.0.1:3007`。
2. 首次登录：账号 `admin`，密码 `admin`。
3. 「账号管理」→ 添加账号，两种方式任选：
   - **输入 Code**：QQ / 微信里打开农场小游戏，30 秒内复制启动参数里的 `code=`，粘进面板。
   - **本机抓包自动填（推荐）**：面板「抓包」卡片点开启代理 → 按提示装本地 CA 证书 → 在 QQ 或微信里重进小游戏 → Code 自动抓取并写入账号。QQ 与微信共用同一套代理和证书，按 `platform` 自动区分，微信账号会顺带填入 `openID`。
4. 「定时启停」按账号设置允许在线时段，避免整夜挂机。
5. 「版本与更新」：点「检查发布版」→ 有新版先显示更新内容 → 点「下载并安装」，面板显示进度和剩余时间，安装不弹黑窗。

## 自带功能

- 内置 MITM 抓包，自动填入 QQ / 微信 Code（按平台区分，微信同时回填 openID）
- 掉线处理：清除失效旧 Code，抓到新 Code 后写回账号
- 账号定时启停：只在设定时段内自动登录
- NapCat 插件免扫码补 Code
- 自动更新：面板一键检查 / 下载 / 安装，更新源内置，下载进度 + 剩余时间，安装无黑窗
- 每个版本附更新内容说明（Release 正文、清单 `notes`、面板「版本与更新」卡片均可见）

## 常见问题

- **连接被拒绝 `code=400`**：Code 已失效或平台参数不对，重新抓一次新鲜 Code；微信账号需带 openID（已自动写入）。
- **微信扫码登录报 `WeChat OAuth callback did not provide accesstoken`**：腾讯侧接口行为变化，客户端已做多来源兜底，仍失败请改用「输入 Code / 本机抓包」。
- **NapCat 与桌面 QQ 同号**：不能同时在线，会互踢，二者选一。
- **更新后配置丢失**：配置在 exe 同目录 `data/` 下，替换 exe 不影响，重装时不要删这个目录。
